# 🐾 Zoomies

> **A four-key rhythm game inspired by classic arcade dance games.**
>
> Built with ❤️ by **PixelPaws Studio**.

## 🎮 Features

* 🎵 Four-key rhythm gameplay
* ⚡ Responsive timing engine
* 🏆 Combo, score, accuracy, and grading
* 🎨 Theme support
* 📝 Built-in chart editor
* 📂 StepMania-compatible chart support (`.sm`)
* 🎮 Keyboard and controller support
* 💾 Local player profiles and high scores

## 🚀 Getting Started

### Download

Download the latest Windows release from the **Releases** page.

### Run from Source

```bash
git clone https://github.com/janet-phan/zoomies.git
cd zoomies
pip install -r requirements.txt
python main.py
```

## ❤️ Why "Zoomies"?

Anyone who's lived with a cat (or dog) knows the feeling.

One moment they're peacefully sleeping.

The next...

**Maximum speed. Maximum chaos.**

That same burst of energy inspired the fast-paced rhythm gameplay of **Zoomies**.
